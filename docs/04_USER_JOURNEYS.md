# رحلات المستخدم

## 1. رحلة أول استخدام

1. يفتح المستخدم التطبيق.
2. تظهر Splash ثم Onboarding مختصر.
3. يختار تسجيل الدخول أو إنشاء حساب طالب.
4. ينتقل إلى التدفق المناسب حسب حالة الحساب.

## 2. رحلة تسجيل طالب

1. يختار المستخدم Register Student.
2. يدخل البيانات الأساسية.
3. يرسل النموذج.
4. يستلم OTP إن كان مطلوبا.
5. يؤكد رقم الهاتف أو البريد.
6. ينتقل لإكمال الملف الأكاديمي.

## 3. رحلة إكمال الملف الأكاديمي

1. يدخل الطالب الجامعة أو الكلية أو الاختصاص أو السنة حسب النموذج.
2. يراجع البيانات.
3. يحفظ الملف.
4. يرى حالة اكتمال البيانات أو النواقص.

## 4. رحلة التوثيق

1. يفتح الطالب شاشة SubmitVerification.
2. يرفق البطاقة الجامعية أو البيانات المطلوبة.
3. يرسل الطلب.
4. يرى حالة Pending.
5. عند القبول ينتقل إلى تجربة الطالب الكاملة.
6. عند الرفض يرى السبب وخطوة إعادة الإرسال.

## 5. رحلة الطالب بعد قبول التوثيق

1. يدخل إلى Home.
2. يرى المواد والغروبات والتنبيهات المهمة.
3. يتصفح المواد أو الغروبات المتاحة.
4. يفتح الملفات أو المحادثات أو الطباعة حسب الحاجة.

## 6. رحلة الدخول إلى مادة

1. يفتح الطالب تبويب Subjects.
2. يختار مادة من القائمة.
3. يفتح Subject Details.
4. يرى الوصف، الملفات، والغروبات المرتبطة إن وجدت.

## 7. رحلة الدخول إلى غروب

1. يفتح الطالب تبويب Groups.
2. يتصفح AvailableGroups أو MyGroups.
3. يفتح GroupDetails.
4. يرى وصف الغروب ورابط واتساب إن وجد.
5. يدخل ChatRoom إذا كان يملك الصلاحية.

## 8. رحلة استخدام المحادثة الداخلية

1. يفتح الطالب ChatRoom من تفاصيل الغروب.
2. تظهر آخر الرسائل.
3. يكتب رسالة نصية.
4. يرسل الرسالة.
5. تظهر الرسالة بعد قبولها من الخادم أو تعرض حالة خطأ عند الفشل.
6. يعيد التطبيق الاتصال تلقائيا عند انقطاع WebSocket.

## 9. رحلة فتح ملف داخل التطبيق

1. يفتح الطالب FilesList من مادة أو غروب.
2. يختار ملفا.
3. يرى FileDetails.
4. يضغط فتح داخل التطبيق.
5. يفتح PdfViewer دون زر تنزيل مباشر.
6. عند فشل التحميل تظهر رسالة خطأ وخيار إعادة المحاولة.

## 10. رحلة طلب طباعة

1. يفتح الطالب Printing أو ملفا قابلا للطباعة.
2. يختار CreatePrintOrder.
3. يحدد الخدمة واللون والتجليد والتسليك وعدد النسخ ومكان الاستلام حسب الخيارات القادمة من API.
4. يراجع PrintPriceSummary.
5. يؤكد الطلب.
6. تظهر حالة الطلب في MyPrintOrders.

## 11. رحلة متابعة طلب طباعة

1. يفتح الطالب MyPrintOrders.
2. يختار طلبا.
3. يرى PrintOrderDetails.
4. يتابع الحالة: جديد، قيد المعالجة، جاهز، مستلم، مرفوض أو ملغى.

## 12. رحلة قراءة إشعار

1. يفتح الطالب Notifications.
2. يرى قائمة الإشعارات.
3. يفتح إشعارا.
4. ينتقل إلى الشاشة المرتبطة عند وجود deep link داخلي.

## 13. رحلة إنشاء تذكرة دعم

1. يفتح الطالب SupportTickets.
2. يختار CreateSupportTicket.
3. يحدد التصنيف ويكتب الوصف.
4. يرسل التذكرة.
5. يتابع الردود والحالة من TicketDetails.

## 14. رحلة تسجيل الخروج

1. يفتح الطالب Settings أو Profile.
2. يختار تسجيل الخروج.
3. يؤكد العملية.
4. يمسح التطبيق tokens من التخزين الآمن.
5. يعود المستخدم إلى Login.
