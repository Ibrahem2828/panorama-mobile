# أدوار المستخدمين

## 1. الطالب

| البند      | التفاصيل                                                                                                                                |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| الوصف      | مستخدم جامعي يملك ملفا أكاديميا ويريد الوصول إلى المواد والغروبات والخدمات.                                                             |
| الصلاحيات  | التسجيل، إكمال الملف الأكاديمي، طلب التوثيق، عرض المواد، الانضمام للغروبات المسموحة، المحادثة، فتح الملفات، طلب الطباعة، فتح تذاكر دعم. |
| الشاشات    | Home، Subjects، Groups، ChatRoom، FilesList، PdfViewer، Printing، Notifications، Profile، SupportTickets.                               |
| القيود     | الميزات الحساسة تعتمد على حالة التوثيق والصلاحيات القادمة من الباك إند.                                                                 |
| حالات خاصة | Pending verification، Rejected verification، نقص بيانات أكاديمية، حظر أو تعليق حساب.                                                    |

## 2. المستخدم العادي

| البند      | التفاصيل                                                                                |
| ---------- | --------------------------------------------------------------------------------------- |
| الوصف      | مستخدم أنشأ حسابا ولم يثبت أنه طالب أو لم يكمل ملفه الأكاديمي.                          |
| الصلاحيات  | الدخول، إدارة الحساب، بدء إكمال الملف الأكاديمي، متابعة حالة التوثيق.                   |
| الشاشات    | Login، AcademicProfileSetup، SubmitVerification، VerificationStatus، Profile، Settings. |
| القيود     | لا يصل إلى الغروبات أو الملفات أو الطباعة الحساسة قبل التوثيق إذا قرر الباك إند ذلك.    |
| حالات خاصة | تحويله إلى طالب بعد قبول التوثيق.                                                       |

## 3. الأدمن

| البند      | التفاصيل                                                                                              |
| ---------- | ----------------------------------------------------------------------------------------------------- |
| الوصف      | مسؤول تشغيلي يدير النظام من لوحة التحكم وليس من تطبيق الطالب.                                         |
| الصلاحيات  | إدارة المستخدمين، المواد، الغروبات، الملفات، خدمات الطباعة، الأسعار، أماكن الاستلام، التوثيق، والدعم. |
| الشاشات    | ليست جزءا من تطبيق الموبايل في MVP، لكن التطبيق يعتمد على قراراته القادمة من API.                     |
| القيود     | يجب أن تسجل العمليات الحساسة في Audit Logs لاحقا.                                                     |
| حالات خاصة | تعديل خدمة طباعة أو صلاحية يجب أن ينعكس في التطبيق دون تحديث التطبيق.                                 |

## 4. موظف الطباعة

| البند      | التفاصيل                                                                      |
| ---------- | ----------------------------------------------------------------------------- |
| الوصف      | مستخدم تشغيلي يتابع طلبات الطباعة وحالاتها.                                   |
| الصلاحيات  | عرض الطلبات، تغيير الحالة، تحديد الجاهزية، وربما إدارة الاستلام حسب صلاحياته. |
| الشاشات    | ليست ضمن تطبيق الطالب في MVP إلا إذا تقرر لاحقا بناء واجهة تشغيلية منفصلة.    |
| القيود     | لا يدير أسعارا أو صلاحيات عامة إلا بتفويض.                                    |
| حالات خاصة | طلب ملغى، ملف غير قابل للطباعة، طلب يحتاج مراجعة.                             |

## 5. الدعم الفني

| البند      | التفاصيل                                                              |
| ---------- | --------------------------------------------------------------------- |
| الوصف      | فريق يتعامل مع تذاكر الطلاب ومشاكل الحساب أو الملفات أو الطباعة.      |
| الصلاحيات  | قراءة التذاكر، الرد، تغيير الحالة، طلب معلومات إضافية.                |
| الشاشات    | في التطبيق يظهر للطالب فقط جزء إنشاء ومتابعة التذاكر.                 |
| القيود     | لا يحصل على صلاحيات إدارية خارج نطاق الدعم إلا إذا حدد الباك إند ذلك. |
| حالات خاصة | تذكرة مرتبطة بطلب طباعة أو توثيق مرفوض.                               |

## 6. مشرف الغروب

| البند      | التفاصيل                                                                               |
| ---------- | -------------------------------------------------------------------------------------- |
| الوصف      | مستخدم يملك صلاحيات إدارة غروب أو متابعة محتواه.                                       |
| الصلاحيات  | إدارة وصف الغروب، رابط واتساب، قبول أو ضبط الأعضاء حسب النموذج، وربما متابعة المحادثة. |
| الشاشات    | قد يستخدم لوحة تحكم أو واجهة لاحقة؛ في MVP يظهر أثر قراراته داخل تفاصيل الغروب.        |
| القيود     | لا يتجاوز صلاحيات المادة أو الكلية أو السنة المرتبطة بالغروب.                          |
| حالات خاصة | غروب مغلق، رابط واتساب غير متاح، غروب يحتاج موافقة للانضمام.                           |
