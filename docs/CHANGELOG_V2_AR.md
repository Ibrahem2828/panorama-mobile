# سجل تغييرات Panorama Mobile v2

## الإصدار 2.0.0 — Production Candidate

### تغييرات حرجة

- حذف رحلة `student-account-requests` غير الموجودة في Backend v2.
- توحيد التسجيل إلى Student/Normal + OTP موحد.
- فصل رحلة `normal_user` عن Student Setup.
- استبدال الروابط الخام للملفات بتذاكر وصول مؤقتة.
- استبدال رابط واتساب الخام بتذكرة redirect مؤقتة.
- إضافة تسعير الطباعة من الخادم مع خيارات اللون والوجه والورق والتجليد والاستلام.
- إضافة نظام التقييم والاقتراحات والتصويت.
- إضافة Push Notifications وتسجيل Device Token.
- فرض HTTPS/WSS في نسخ preview/production.
- إضافة التحقق من أصل ومسار روابط العرض قبل فتحها.
- إضافة منع التقاط الشاشة أثناء عرض الملفات قدر الإمكان.

### جودة وتجربة المستخدم

- استعادة جميع أصول الصور والأيقونات المفقودة.
- إضافة حالات اتصال وانقطاع الشبكة.
- إضافة شاشات التقييم، اقتراحاتي، والاقتراحات العامة.
- ربط طلبات التقييم بإجراءات التوثيق، الغروبات، الملفات، الطباعة والدعم.
- تحسين النصوص العربية وحالات Loading/Error/Empty.

### أدوات وجودة

- إضافة `scripts/validate-project.mjs`.
- إضافة اختبارات أولية لعقد التسعير وروابط الخادم الموثوقة.
- إضافة وثائق معمارية وأمنية وعقد تكامل وإصدار.
- حذف lockfile القديم غير المتوافق؛ يجب توليد lockfile جديد قبل CI.
