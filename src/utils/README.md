# utils

أدوات صغيرة وخالية من business logic الثقيل.

- `rtl.ts`: إعداد ودوال مساعدة للـ RTL مثل textAlign وflexDirection وstart/end spacing.
- `logger.ts`: logger production-safe مع redaction للمفاتيح الحساسة.
- `strings.ts`: أدوات نصية صغيرة مثل trim آمن واستخراج initials.

لا تضف هنا منطق feature أو API. ضع ذلك داخل نطاق الميزة المناسبة لاحقا.
