# common

مكونات عامة قابلة لإعادة الاستخدام في كل التطبيق.

- `AppText`: النص الموحد للـ typography والألوان وRTL.
- `AppButton`: زر أساسي للحالات primary/secondary/outline/ghost/danger.
- `AppIconButton`: زر أيقونة مع accessibility label.
- `AppBadge`: شارة status أو brand.
- `AppAvatar`: initials أو صورة.
- `Divider`: فاصل أفقي.

هذه المكونات لا تحتوي business logic ولا تستدعي API.
