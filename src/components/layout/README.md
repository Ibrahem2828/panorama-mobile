# layout

مكونات تنظيم الشاشة والمسافات.

- `AppScreen`: حاوية شاشة مع safe area وscroll وpadding موحد.
- `AppCard`: بطاقة قابلة لاختيار variant وpadding.
- `AppHeader`: عنوان شاشة بسيط بدون navigation logic.
- `PlaceholderScreen`: شاشة مؤقتة موحدة لمراحل بناء navigation.
- `SectionHeader`: عنوان قسم مع action اختياري.
- `Stack`: ترتيب children عموديا أو أفقيا مع gap.

استخدم هذه المكونات لتقليل تكرار layout styles في الشاشات القادمة.
