- اختيار ملف مسموح وقابل للطباعة.
- عدد النسخ، اللون، الوجه، حجم الورق، التجليد، نقطة الاستلام.
- طلب Quote من الخادم قبل التأكيد.
- إعادة الحساب عند إنشاء الطلب وحفظ pricing snapshot في Backend.
- متابعة الحالات والإلغاء حسب transition rules.
- لا يرسل الموبايل `price` أو `total_price` مطلقًا.
